# 🚀 Dev Journey: Repositório de Treinamento

<br>

## 🔭 Visão Geral

Este repositório serve como um hub central para todos os meus projetos de estudo, exercícios e treinamentos práticos. O objetivo é documentar minha evolução em diferentes tecnologias, organizando códigos que variam desde fundamentos de linguagens até a construção de APIs e interfaces complexas. 

A estrutura é organizada em subpastas por tecnologia, facilitando a navegação e o estudo isolado de cada conceito ou linguagem.

<br>

## 🛠️ Tecnologias em Foco

Atualmente, o repositório contém projetos focados em:

- **Back-end:** PHP, Node.js (Express.js)
- **Front-end:** React.js
- **Bancos de Dados:** MySQL
- **Full-stack:** Integrações entre as tecnologias citadas acima

<br>

## 🎯 Conteúdo e Funcionalidades

- ✅ **Organização por Linguagem:** Pastas específicas para PHP, JavaScript, SQL, etc.
- ✅ **Exploração de APIs:** Implementações de CRUDs e rotas utilizando Express.js.
- ✅ **Gestão de Dados:** Scripts e estruturas de banco de dados MySQL.
- ✅ **Interfaces Modernas:** Componentização e gerenciamento de estados com React.js.
- ✅ **Evolução Gradual:** Projetos de pequeno e médio porte focados em fixação de sintaxe e lógica de programação.

<br>

## 📌 Status do Repositório

- 🛠️ **Em desenvolvimento contínuo.** Novos diretórios e exemplos de código são adicionados conforme avanço nos estudos de novas stacks e conceitos de arquitetura.

## 🧭 Como Executar os Projetos

Como este repositório agrupa tecnologias distintas, a execução varia conforme a pasta:

1. **Projetos PHP:** Requerem um servidor local (como Apache via XAMPP/WAMP).
2. **APIs Node.js:** Navegue até a pasta, execute `npm install` e depois `node index.js`.
3. **Projetos React:** Utilize `npm install` e `npm run dev` para visualizar no navegador.
4. **Banco de Dados:** Os arquivos `.sql` para criação das tabelas costumam estar na raiz da respectiva pasta do projeto.
